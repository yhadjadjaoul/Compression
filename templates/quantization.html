Quantization Formulas

1. Scale factor calculation (S):

If Quality < 50: S = 5000 / Quality; Else: S = 200 - 2 * Quality

2. Table adjustment (Q):

Qresulting(i,j) = max(1, min(255, floor((Qbase(i,j) * S + 50) / 100)))

3. Application (Compression & Decompression):

QuantizedValue(i,j) = round(DCTValue(i,j) / Q(i,j))
ReconstructedValue(i,j) = QuantizedValue(i,j) * Q(i,j)
