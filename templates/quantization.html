Formules de Quantification

1. Calcul du facteur d'échelle (S) :

Si Qualité < 50 : S = 5000 / Qualité ; Sinon : S = 200 - 2 * Qualité

2. Ajustement de la table (Q) :

Qrésultante = floor((Qbase * S + 50) / 100)

3. Application (Compression & Décompression) :

Valeurquantifiée = round(ValeurDCT / Q)
Valeurreconstruite = Valeurquantifiée * Q
